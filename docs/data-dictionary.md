# LexiContract Data Dictionary

This document maps out all database tables in the LexiContract system, including column types, constraints, and descriptions.

## Tables

### 1. `vendor`
Stores information about vendors providing services.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `vendor_id` | `BIGINT` | PRIMARY KEY, GENERATED BY DEFAULT AS IDENTITY | Unique identifier for the vendor |
| `name` | `TEXT` | NOT NULL | Name of the vendor |
| `registration_number` | `TEXT` | UNIQUE | Business registration number |
| `contact_email` | `TEXT` | | Contact email address |
| `contact_phone` | `TEXT` | | Contact phone number |
| `created_at` | `TIMESTAMP WITH TIME ZONE` | DEFAULT NOW() | Timestamp of creation |

### 2. `users`
Stores user account information.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `user_id` | `BIGINT` | PRIMARY KEY, GENERATED BY DEFAULT AS IDENTITY | Unique identifier for the user |
| `email` | `TEXT` | NOT NULL, UNIQUE | User email address |
| `password_hash` | `TEXT` | NOT NULL | Hashed password |
| `role` | `TEXT` | NOT NULL | User role (e.g., ADMIN, REVIEWER) |
| `created_at` | `TIMESTAMP WITH TIME ZONE` | DEFAULT NOW() | Timestamp of creation |

### 3. `contract`
Stores contract details.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `contract_id` | `BIGINT` | PRIMARY KEY, GENERATED BY DEFAULT AS IDENTITY | Unique identifier for the contract |
| `vendor_id` | `BIGINT` | REFERENCES vendor(vendor_id) | Associated vendor |
| `created_by` | `BIGINT` | REFERENCES users(user_id) | User who created the contract |
| `title` | `TEXT` | NOT NULL | Title of the contract |
| `contract_type` | `TEXT` | NOT NULL | Type of contract (e.g., MSA, SOW) |
| `status` | `TEXT` | NOT NULL | Status of the contract (e.g., DRAFT, ACTIVE) |
| `start_date` | `DATE` | NOT NULL | Start date of the contract |
| `end_date` | `DATE` | NOT NULL | End date of the contract |
| `created_at` | `TIMESTAMP WITH TIME ZONE` | DEFAULT NOW() | Timestamp of creation |

### 4. `milestone`
Stores milestones associated with contracts.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `milestone_id` | `BIGINT` | PRIMARY KEY, GENERATED BY DEFAULT AS IDENTITY | Unique identifier for the milestone |
| `contract_id` | `BIGINT` | REFERENCES contract(contract_id) | Associated contract |
| `description` | `TEXT` | NOT NULL | Description of the milestone |
| `due_date` | `DATE` | NOT NULL | Due date for the milestone |
| `amount` | `NUMERIC` | NOT NULL | Amount associated with the milestone |
| `status` | `TEXT` | NOT NULL | Status of the milestone (e.g., PENDING, COMPLETED) |

### 5. `clause`
Stores clauses within contracts.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `clause_id` | `BIGINT` | PRIMARY KEY, GENERATED BY DEFAULT AS IDENTITY | Unique identifier for the clause |
| `contract_id` | `BIGINT` | REFERENCES contract(contract_id) | Associated contract |
| `clause_type` | `TEXT` | NOT NULL | Type of clause (e.g., Termination, Liability Cap) |
| `clause_text` | `TEXT` | NOT NULL | Text of the clause |
| `is_flagged` | `BOOLEAN` | DEFAULT FALSE | Flagged for risk review |

### 6. `standard_clause`
Stores standard clauses for reference.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `clause_id` | `BIGINT` | PRIMARY KEY, GENERATED BY DEFAULT AS IDENTITY | Unique identifier for the standard clause |
| `clause_type` | `TEXT` | NOT NULL | Type of clause |
| `clause_text` | `TEXT` | NOT NULL | Text of the clause |
| `embedding` | `vector` | | Vector embedding for similarity search |

### 7. `approval_step`
Stores approval steps for contracts.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `step_id` | `BIGINT` | PRIMARY KEY, GENERATED BY DEFAULT AS IDENTITY | Unique identifier for the approval step |
| `contract_id` | `BIGINT` | REFERENCES contract(contract_id) | Associated contract |
| `step_name` | `TEXT` | NOT NULL | Name of the approval step |
| `status` | `TEXT` | NOT NULL | Status of the step (e.g., PENDING, APPROVED) |
| `assigned_to` | `BIGINT` | REFERENCES users(user_id) | User assigned to the step |

### 8. `audit_log`
Stores audit logs for system actions.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `log_id` | `BIGINT` | PRIMARY KEY, GENERATED BY DEFAULT AS IDENTITY | Unique identifier for the audit log |
| `user_id` | `BIGINT` | REFERENCES users(user_id) | User who performed the action |
| `action` | `TEXT` | NOT NULL | Action performed |
| `table_name` | `TEXT` | | Affected table |
| `record_id` | `BIGINT` | | Affected record ID |
| `created_at` | `TIMESTAMP WITH TIME ZONE` | DEFAULT NOW() | Timestamp of the action |
